Install on iPhone

In Safari, tap Share ⬆ → Add to Home Screen → Add. Then open Code Blue from the home screen icon.

iPhone: keep Code Blue on screen during a code

iPhone does not allow web apps to ring when locked or in the background. The screen stays on automatically while a code runs. Keep media volume up.

Allow on-time alarms

Android needs "Alarms & reminders" permission so alarms ring exactly on time when the screen is locked.
